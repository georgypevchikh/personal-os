Personal OS

A local-first memory layer that lets AI agents work with one person across months, tools and devices — without forgetting context, repeating mistakes, or leaking anything private.

View on GitHub Case studies Architecture
The idea

Chat is where work happens. Files are where truth lives.

Every agent session loads the same small, current picture of what is true, reads deeper only on demand, and writes back what it learned. Plain Markdown and git, so any runtime — and a phone — reads the same memory.

How it was built

Every mechanism exists because something broke

The rule: if a rule is broken twice, turn it into a mechanism or delete it. The counter-rule: automate only what a machine can judge.
